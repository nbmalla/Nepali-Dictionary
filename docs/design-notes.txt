========================================================================
Nep Dictionary Web App — 画面構成案 & 音声読み上げ(TTS)実装方針
（Gensparkへのプロンプトにそのまま貼り付けて使える設計メモ）
========================================================================

■ 全体ナビゲーション構成

1. ホーム画面（カテゴリー一覧）
   - 25カテゴリーをグリッド/リストで表示
     - 各カードに: アイコン(絵文字) + 日本語ラベル + ネパール語ラベル
     - 進捗バッジ（例: 6/12 覚えた）
   - 上部に検索バー（日本語 or ネパール語でフレーズ検索）
   - 「今日のフレーズ」としてランダムに1項目をピックアップ表示
   - カテゴリー並び順・アイコンは Nep dictionary.txt 冒頭の
     「Suggested category order & icons」コメント表を参照

2. カテゴリー詳細画面（フラッシュカード一覧）
   - 選択カテゴリーの LessonItem 一覧をカード形式で表示
   - isKnowledgeCategory(categoryId) で表示UIを自動分岐:
     - true（知識カード）: タイトル(primary) + 説明文(meaning/note)を
       そのまま読み物として表示。フリップ動作は不要。
     - false（フレーズカード）: 表=primary+romaji、裏=meaning+note。
       タップでフリップするフラッシュカードUI。
   - 各カードに 🔊 音声読み上げボタン（primaryの日本語のみ対応、詳細は後述）
   - 「覚えた / まだ」のチェックで進捗を記録（ローカル保存でOK、初期版はDB不要）

3. フラッシュカード練習モード（フレーズ系カテゴリーのみ）
   - スワイプ形式（Tinderライク）で1枚ずつ出題
   - 「わかった」→ 次のカードへ、「もう一度」→ 後半で再出題
   - セッション終了後に正答率サマリーを表示

4. 設定画面
   - UI表示言語切替（日本語 ⇔ ネパール語）
   - フォントサイズ調整（初心者/高齢者にも読みやすく）
   - 読み上げ速度の調整

■ レスポンシブ方針
   - モバイル幅: カテゴリー一覧は1カラムのリスト表示
   - デスクトップ幅: カテゴリー一覧は3〜4カラムのグリッド表示
   - フラッシュカードは常に画面中央に1枚表示（幅max 480px程度）

■ データ構造との対応
   - lessonItemsByCategory（Nep dictionary.txt）がコンテンツ本体
   - lib/data/lesson_data.dart 側でカテゴリーごとの
     id / icon / 表示順 / ラベル（日本語・ネパール語） をメタ情報として管理
   - isKnowledgeCategory() は既存のまま、UI分岐ロジックに活用できる


========================================================================
■ 音声読み上げ（TTS）機能案
========================================================================

【技術選定】
- flutter_tts パッケージ（Flutter公式互換の定番プラグイン）
  - モバイル(iOS/Android)・Web共通で動作
  - Web版はブラウザのWeb Speech API (SpeechSynthesis) をラップして動作するため
    追加サーバー費用なし
  - 日本語は "ja-JP" を指定すればOS/ブラウザ内蔵の日本語音声エンジンで読み上げ可能

【対応範囲の注意点】
- primary（日本語フレーズ）の読み上げ: 問題なく対応可能
- meaning（ネパール語訳）の読み上げ: ブラウザ内蔵TTSに ne-NP（ネパール語）
  音声が入っていない環境が多く、非対応になる可能性が高い
  → 初期版は「日本語のみ読み上げ」に割り切るのが現実的
  → 将来的にネパール語も読み上げたい場合は、Google Cloud Text-to-Speech
    （ne-NP音声あり）等の有料クラウドAPIを別途検討

【実装イメージ（Gensparkへの指示にそのまま使える概要）】
    import 'package:flutter_tts/flutter_tts.dart';

    final FlutterTts flutterTts = FlutterTts();

    Future<void> speakJapanese(String text) async {
      await flutterTts.setLanguage("ja-JP");
      await flutterTts.setSpeechRate(0.4); // 学習者向けにゆっくりめ
      await flutterTts.speak(text);
    }

  - 各カードの primary テキスト横に 🔊 ボタンを配置し、
    speakJapanese(item.primary) を呼び出すだけで実装可能
  - romaji表示をユーザーが隠せるようにすれば、音声だけを頼りに
    聞き取り練習をするモードも作れる

【コスト・注意点】
  - flutter_tts 自体は無料（端末/ブラウザ内蔵のTTSエンジンを利用するため）
  - 声質はOS/ブラウザ依存（Windows・Android・iOSで声が異なる）
  - より自然な音声にしたい場合は Google Cloud TTS / Amazon Polly 等の
    有料API連携が必要（従量課金、月間利用量次第でコスト増）
  - 初期リリースでは flutter_tts の無料枠で十分と考えられる
